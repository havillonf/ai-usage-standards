## Anthropic — engenharia

- **[Building effective agents](https://www.anthropic.com/engineering/building-effective-agents)** (dez. 2024). Distingue *workflows* de *agentes*, defende soluções simples e a interface agente–computador. É a base dos [Princípios](/aprofundar/principios).
- **[Effective context engineering for AI agents](https://www.anthropic.com/engineering/effective-context-engineering-for-ai-agents)** (set. 2025). Trata de *context rot*, orçamento de atenção, recuperação *just in time*, compactação, notas estruturadas e subagentes. É a base de [Gestão de contexto](/aprofundar/gestao-de-contexto).
- **[Equipping agents for the real world with Agent Skills](https://www.anthropic.com/engineering/equipping-agents-for-the-real-world-with-agent-skills)** (out. 2025). Apresenta skills e *progressive disclosure*.
- **[Writing effective tools for agents](https://www.anthropic.com/engineering/writing-tools-for-agents)** (set. 2025). Explica como desenhar e avaliar ferramentas e servidores MCP para agentes.

## Anthropic — documentação do Claude Code

- **[Best practices for Claude Code](https://code.claude.com/docs/en/best-practices)**. Reúne o fluxo explorar → planejar → implementar → verificar, como pedir, gestão de contexto e antipadrões. Base de [Fluxo de trabalho](/aprofundar/ciclo-de-trabalho).
- **[How Claude remembers your project](https://code.claude.com/docs/en/memory)**. Cobre CLAUDE.md, AGENTS.md e memória automática.
- **[Configure permissions](https://code.claude.com/docs/en/permissions)**. Detalha regras allow/ask/deny e os modos de permissão.

## Padrões abertos

- **[AGENTS.md](https://agents.md/)**: formato aberto de instruções de projeto, mantido pela Agentic AI Foundation.

## Segurança

- **[OWASP Top 10 for LLM Applications](https://genai.owasp.org/llm-top-10/)**: prompt injection, vazamento de informação sensível, cadeia de suprimentos e excesso de agência.
- **Simon Willison — [The lethal trifecta for AI agents](https://simonwillison.net/2025/Jun/16/the-lethal-trifecta/)** (jun. 2025): a combinação de dados privados, conteúdo não confiável e comunicação externa.
- **Spracklen et al. — [Package hallucinations](https://arxiv.org/abs/2406.10279)** (USENIX Security 2025): estudo sobre pacotes inventados por LLMs (*slopsquatting*).
